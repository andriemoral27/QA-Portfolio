# API Testing

## Overview

This repository contains sample process of API Testing on variety of endpoints using RESTful API. This includes tools, methods and HTTP response outputs

---
## Tools Used
This is the tool that I used to test API Endpoints 
- Postman
---

## HTTP Methods 
This are the methods used to test API endpoints

| Method | Purpose |
| :--- | :--- |
| `GET` | Retrieve data from a server without modifying it |
| `POST` | Send data to a server to create a new resource |
| `PUT` | Update an existing resource or replace it completely |
| `DELETE` | Remove a specified resource from the server |
---

## HTTP Response Status Codes
This are the common response status codes output when conducting API Testing

| Status Code | Status Text | Description |
| :---: | :--- | :--- |
| `200` | OK | Request is successfully submitted |
| `201` | Created | Resource successfully created |
| `400` | Bad Request | Missing required parameters or malformed payload |
| `401` | Unauthorized | Authentication required or invalid/expired token |
| `404` | Not Found | Requested endpoint or resource does not exist |
